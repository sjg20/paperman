Keyboard shortcuts
==================

Most of what Paperman does has a key, shown beside it in the menus. They
are gathered here.

Anywhere
--------

.. list-table::
   :widths: 30 70

   * - **Ctrl+F**, **F4**
     - Go to a folder, by typing part of its name. While the scan panel
       is open, these go to its folder box instead, from anywhere
   * - **Ctrl+S**
     - Search the folder selected and those inside it
   * - **Ctrl+Shift+F**
     - Hide the folders named for another year or month, or show them
       again
   * - **Ctrl+A**
     - Select every stack in the stack pane
   * - **Ctrl+Z**, **Ctrl+Shift+Z**
     - Undo and redo
   * - **Ctrl+P**
     - Print the stacks selected, or the page shown in the page view
   * - **F5**
     - Scan now, with the scan panel's settings
   * - **F6**
     - Open the scan panel
   * - **F11**
     - Fill the screen, or go back to a window
   * - **Alt+Shift+W**, **Alt+Shift+D**
     - Show the files in your Downloads or Documents folder in the stack
       pane, to file them
   * - **Alt+Shift+F**
     - Show the files in a folder chosen, in the same way
   * - **Ctrl+Q**
     - Quit Paperman

Stacks
------

These act on the stacks selected in the stack pane (see :doc:`filing`).

.. list-table::
   :widths: 30 70

   * - Arrow keys
     - Move from stack to stack
   * - **Ctrl+G**
     - Stack: put the stacks selected together into one
   * - **Ctrl+I**
     - Unstack page: take the page shown out, into a stack of its own
   * - **Ctrl+U**
     - Unstack all: split each stack into a stack for each page
   * - **Ctrl+D**
     - Duplicate each stack
   * - **Ctrl+M**
     - Move the stacks to another folder
   * - **Del**
     - Delete the stacks, after asking
   * - **F2**
     - Rename the stack
   * - **Shift+F2**
     - Rename the page shown
   * - **Alt+Left**, **Alt+Right**
     - Turn every page of the stacks to the left or to the right
   * - **Ctrl+Shift+L**
     - In the results of a search, go to the folder the stack is in
   * - **Esc**
     - Go back to the folder, from the results of a search or from files
       being imported

Duplicating
~~~~~~~~~~~

.. list-table::
   :widths: 30 70

   * - **Ctrl+Shift+I**
     - Copy the page shown into a stack of its own
   * - **Ctrl+Shift+D**
     - Copy each stack as a ``.max`` stack
   * - **Ctrl+Shift+P**
     - Copy each stack as a PDF
   * - **Ctrl+Shift+J**
     - Copy each page as a JPEG picture

Emailing and copying
~~~~~~~~~~~~~~~~~~~~

See :doc:`sharing`.

.. list-table::
   :widths: 30 70

   * - **Ctrl+E**
     - Email the stacks as they are kept
   * - **Ctrl+Alt+E**
     - Email them as ``.max`` stacks
   * - **Ctrl+Shift+E**
     - Email them as PDFs
   * - **Ctrl+C**
     - Copy them to the clipboard as PDFs

Page view
---------

.. list-table::
   :widths: 30 70

   * - **Esc**
     - Go back to the desktop view

Scan panel
----------

These work while the scan panel is open (see :doc:`scanning`).

.. list-table::
   :widths: 30 70

   * - **Ctrl+F**, **F4**
     - Go to the folder box, to type part of the name of the folder to
       scan into
   * - **Ctrl+1** to **Ctrl+5**
     - Choose the first five presets in the list
   * - **Alt+A**
     - Scan on A4 paper
   * - **Alt+L**
     - Scan on US legal paper, or on letter when it is legal already
