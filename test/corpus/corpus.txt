# Real pages from a Ricoh fi-8950, kept as the scanner sent them, with
# what paperman should make of each. They are fed sideways, as a book
# guillotined into loose sheets is, and they are the record of how
# auto-colour and the sheet-edge crop behave on the kinds of page a
# book holds, so that tuning one kind cannot quietly change another.
#
# To add a page, scan it with PAPERMAN_KIND_DEBUG set to a directory:
#
#   PAPERMAN_KIND_DEBUG=/tmp/pages ./paperman --scan --repo DIR \
#      --dir inbox --pages 2 --auto-colour --sideways right
#
# which writes the scanner's own data as pageN.jpg and prints the counts
# behind the decision. Copy the page in under a name saying what it
# holds, and add a line here.
#
# file  sideways(none|left|right)  depth(1|8|24)  height  what it holds
#
# A height of 0 asks for no check; otherwise it is the height the page
# should be stored at, and it must come out within a fiftieth of it.
