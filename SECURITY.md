# Security

## Reporting a problem

Please report a security problem privately, not in a public issue:
use **Report a vulnerability** on the
[Security tab](https://github.com/sjg20/paperman/security) of this
repository. Only the maintainers see the report, and they can discuss it
with you there and publish an advisory once it is fixed.

Say what is affected (the desktop program, `paperman-server`, the app or
the demo at demo.getpaperman.com), how to reproduce the problem, and what
someone could do with it.

## What is supported

Fixes go into the next release, so use the latest one. Paperman is
looked after by one person in their spare time: there is no fixed time
for a reply, but reports are taken seriously.
